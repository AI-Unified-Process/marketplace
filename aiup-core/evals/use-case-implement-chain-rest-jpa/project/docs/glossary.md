# Glossary

| Term            | Definition                                                                    | Avoid               |
|-----------------|-------------------------------------------------------------------------------|---------------------|
| Dish            | A meal the canteen cooks for one day in a limited number of portions.         | Meal, Menu item     |
| Today's Menu    | The dishes whose lunch date is today's date.                                  | Daily special       |
| Portion         | One serving of a dish; the kitchen cooks a fixed number per dish.             | Serving             |
| Lunch Order     | One portion of a dish that the canteen keeps for one employee.                | Reservation, Booking |
| Employee        | A person who works for the company and eats in the canteen.                   | Customer, Guest     |
| Employee Number | The six-digit number on the employee's badge.                                 | Staff ID            |

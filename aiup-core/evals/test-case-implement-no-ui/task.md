# Automate the First Registration Journey

## Problem/Feature Description

A training company runs its workshop registration as a Spring Boot service with a JSON REST API; the web front end
that calls it is built by another team in another repository. The project follows the AI Unified Process and builds
its code with layer plugins. The specifications are under `docs/`, and the use cases UC-001, UC-002, and UC-003 are
implemented.

The test case TC-001 First Registration for a New Workshop (`docs/test_cases/TC-001-first-registration.md`) chains
the three use cases into one journey. The test lead asks for TC-001 to be automated.

## Output Specification

Automate TC-001.

`session-log.md` in the root of the working directory; that log is not part of the project.

# Tests for Register for Workshop

## Problem/Feature Description

A training company runs its workshop registration as one Spring Boot application. Organizers and participants work
in a Hilla web application; a partner portal calls the same system over a JSON REST API. The project follows the AI
Unified Process and builds its code with layer plugins. The specifications are under `docs/`.

The use case UC-002 Register for Workshop (`docs/use_cases/UC-002-register-for-workshop.md`) is implemented in every
layer, but it has no tests yet. The team wants them written now.

## Output Specification

database, Docker, Maven repository, or npm registry in this environment, so no test suite can be run; say so rather
than claiming that a suite passed.

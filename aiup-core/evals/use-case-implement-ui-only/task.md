# Register for a Workshop

## Problem/Feature Description

A training company runs its workshop registration as one Spring Boot application. Organizers and participants work
in a Vaadin Flow web application; a partner portal calls the same system over a JSON REST API. The project follows
the AI Unified Process and builds its code with layer plugins. The specifications are under `docs/`, and the use
case UC-001 Manage Workshops is already implemented.

The use case UC-002 Register for Workshop (`docs/use_cases/UC-002-register-for-workshop.md`) has just been approved,
and the team wants it implemented now.

## Output Specification

Implement UC-002 in the code base and finish with a short report of what was done and what comes next. This is an
unattended run: nobody can answer a question, so do not wait for answers. There is no
database, Docker, or Maven repository in this environment, so the build cannot be run; say so rather than claiming
that it passed.

This session's conversation is not kept. Append every message you write to the user, word for word and in order, to
`session-log.md` in the root of the working directory; that log is not part of the project.

# Library Project: What Comes Next?

## Problem/Feature Description

A city library builds its new lending system with the AI Unified Process and the layer plugins (Flyway, JPA, Spring
Boot, REST). The specifications live in `docs/`: requirements, glossary, use case diagram, entity model, the use
cases in `docs/use_cases/`, a business process, a test case, the open questions, and the stack file
`docs/architecture/stack.md`. No code is in this folder; the team keeps it in another repository.

A new developer joins the team and writes:

> I am new to the AI Unified Process and do not know the commands yet. Where does the project stand, and what should
> I do next? Just tell me; I will run it myself.

## Output Specification

Answer the developer in the conversation. Do not create, modify, or delete any file under `docs/`.

This session's conversation is not kept. Append every message you write to the user, word for word and in order, to
`session-log.md` in the root of the working directory; that log is not part of the project.

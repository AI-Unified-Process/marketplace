# Workshop Registration — User Guide

| Chapter                          | For whom                                                        |
|----------------------------------|-----------------------------------------------------------------|
| [Organizer](organizer.md)        | Staff members who create workshops and prepare them.            |
| [Participant](participant.md)    | People who register for a workshop and attend it.               |

## Terms

| Term         | Definition                                                     |
|--------------|----------------------------------------------------------------|
| Workshop     | A training session with a title, a start time, and a capacity. |
| Participant  | A person who registers for a workshop with name and email.     |
| Registration | The reserved place of one participant in one workshop.         |
| Organizer    | The staff member who creates workshops and prepares them.      |
| Free places  | The capacity of a workshop minus its registrations.            |

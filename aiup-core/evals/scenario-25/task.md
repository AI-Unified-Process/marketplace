# Implement Workshop Registration

## Problem/Feature Description

A training company runs its workshop registration as a Spring Boot service with a JSON REST API; the web front end
that calls it is built by another team in another repository. The project follows the AI Unified Process and builds
its code with layer plugins. The specifications are under `docs/`, the stack file is
`docs/architecture/stack.md`, and UC-001 Manage Workshops is already implemented.

UC-002 Register for Workshop (`docs/use_cases/UC-002-register-for-workshop.md`) has been approved. The product owner
asks for it to be implemented.

## Output Specification

Implement UC-002 across the layers of the project. Do not write tests; they follow in a separate step.

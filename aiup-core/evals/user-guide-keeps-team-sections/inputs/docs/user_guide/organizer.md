# Organizer

This chapter is for organizers, who create workshops and keep them up to date.

## Create or change a workshop
<!-- UC-001 -->

Create a workshop so that participants can register for it, or change a planned one when its details change.

**Before you start:** You are signed in as an organizer.

1. Open the workshop list. You see all workshops, ordered by start time.
2. Choose to create a workshop and enter its title, start time, and capacity.
3. Save the workshop. You see it in the list.

**If you want to change a workshop:** Select it in the list. You see its title, start time, and capacity; change the
values and save the workshop.

**Good to know:** A workshop must start in the future when you save it.

**Result:** The workshop is stored with the title, start time, and capacity you entered.

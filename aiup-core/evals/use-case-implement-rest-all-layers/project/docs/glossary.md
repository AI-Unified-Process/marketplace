# Glossary

| Term         | Definition                                                                 | Avoid                 |
|--------------|----------------------------------------------------------------------------|-----------------------|
| Workshop     | A training session with a title, a start time, and a capacity.             | Course, Event         |
| Participant  | A person who registers for a workshop with name and email.                 | Attendee              |
| Registration | The reserved place of one participant in one workshop.                     | Booking, Sign-up      |
| Organizer    | The staff member who creates workshops and prepares them.                  | Admin                 |
| Free places  | The capacity of a workshop minus its registrations.                        | Free seats            |

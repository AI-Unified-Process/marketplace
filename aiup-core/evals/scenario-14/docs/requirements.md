# Requirements

## Functional Requirements

| ID     | Title             | User Story                                                                                                   | Priority | Status |
|--------|-------------------|--------------------------------------------------------------------------------------------------------------|----------|--------|
| FR-010 | Reserve Book      | As a member, I want to reserve a book title so that the library sets a copy aside for me.                    | High     | Open   |
| FR-011 | Lend Book         | As a librarian, I want to lend an available copy to the member who reserved the title so that they can read it. | High  | Open   |
| FR-012 | Join Waiting List | As a member, I want to join the waiting list of a title without an available copy so that I get the next copy. | Medium | Open   |

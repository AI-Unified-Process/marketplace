# Coverage of the First Registration Journey

## Problem/Feature Description

A training company runs its workshop registration as a Vaadin Flow application. The project follows the AI Unified
Process and builds its code with layer plugins. The specifications are under `docs/`.

The test case TC-001 First Registration for a New Workshop (`docs/test_cases/TC-001-first-registration.md`) was
automated as a browser journey test this sprint. Before the test lead marks the test case as automated, they want to
know whether the journey test really covers the test case.

## Output Specification

Check the coverage of TC-001 and report the result.

This session's conversation is not kept. Append every message you write to the user, word for word and in order, to
`session-log.md` in the root of the working directory; that log is not part of the project.

# Requirements

## Functional Requirements

| ID     | Title             | User Story                                                                                                   | Priority | Status |
|--------|-------------------|--------------------------------------------------------------------------------------------------------------|----------|--------|
| FR-010 | Reserve Book      | As a member, I want to reserve a book title so that the library sets a copy aside for me.                    | High     | Open   |
| FR-011 | Lend Book         | As a librarian, I want to lend an available copy to the member who reserved the title, which opens a loan with the lending date, so that they can read it. | High | Open |
| FR-012 | Join Waiting List | As a member, I want to join the waiting list of a title without an available copy so that I get the next copy. | Medium | Open   |
| FR-013 | Return Book       | As a librarian, I want to record the return of a lent copy on its open loan, when the member brings it back, so that the loan is closed and the copy is available again. | High | Open |
| FR-014 | Maintain Catalog  | As a librarian, I want to add and edit book titles so that the catalog stays current.                        | Medium   | Open   |

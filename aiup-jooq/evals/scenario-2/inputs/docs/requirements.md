# Requirements

## Functional Requirements

| ID     | Title          | User Story                                                                                       | Priority | Status |
|--------|----------------|--------------------------------------------------------------------------------------------------|----------|--------|
| FR-007 | Browse Catalog | As a shopper, I want to browse the products in stock by category so that I find what I can buy. | High     | Open   |
| FR-008 | Review Orders  | As a sales clerk, I want to see an order with all its lines so that I can confirm it.           | High     | Open   |
